# Football Match Analysis Dashboard

Portfolio dashboard for a Performance Analyst application to the AIFF-FIFA-Odisha Talent Academy. It demonstrates the workflows expected in a high-performance football environment: match review, opposition scouting, video tagging, player development insights, and staff-ready reporting.

## Highlights

- Match command centre with score context, xG, pressing, territory, possession, and phase-of-play KPIs.
- Tactical pitch view for shot maps, recoveries, and chance zones.
- Timeline and momentum views for pre-, live-, and post-match analysis.
- Player development panel with workload, technical contribution, and coaching actions.
- Opposition scouting cards and video-tag style event log.
- Responsive, presentation-ready UI for staff meetings and player feedback.

## Tech Stack

- React
- TypeScript
- Vite
- Recharts
- Lucide React

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Why This Project Fits The Role

The dashboard is designed around the responsibilities listed for the Performance Analyst role: interpreting internal and external football data, creating meaningful visualizations, supporting tactical planning, maintaining a searchable analysis workflow, and translating match evidence into actionable coaching points.
